# 开发日志 — 2026-08-21

## 事件

### Supabase 再次警告「低活跃度」⚠️

- **现象**：收到 Supabase 邮件，项目（`mkbcbfzfrdrqywzjbrbu`）已超过 7 天「没有足够活动」，即将被暂停
- **排查**：keep-alive workflow 一直在正常跑（08-12 / 08-16 / 08-19 三次 schedule 全部 success，HTTP 200）
- **根因**：Supabase 的活动检测基于**数据库活动**，SELECT 查询可能被缓存命中而不计入；
  REST 层返回 200 不代表数据库计时器被重置。需要**真实写操作（INSERT）**
- **教训**：workflow 成功 ≠ 保活有效。验证手段必须与被检测的指标一致
