## 事件

### Supabase 政策变更通知：Data API 不再自动授权新表

收到 Supabase 官方邮件：

> 自 **2026-10-30** 起，`public` schema 中**新建的表**不再自动获得 Data API 访问权限；
> 必须在建表迁移里显式 `GRANT`，否则 API 返回 permission denied。
> **现有表不受影响**（保留当前授权），"No action is required to keep your app running"。

## 分析结论

| 范围 | 影响 | 处理 |
|------|------|------|
| 本项目现有 8 张表 | ✅ 不受影响，授权保留 | 仅"显式化"记录，无运行影响 |
| 2026-10-30 后新建的表 | ⚠️ 必须显式 GRANT，否则前端报 `permission denied (42501)` | 已在规范中强制要求 |
| 新建库 / 本地 db reset / preview 分支 | 同样需要显式授权 | schema.sql 已补齐 |
